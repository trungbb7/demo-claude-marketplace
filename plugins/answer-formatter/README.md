# Plugin: Answer Formatter

Plugin giúp tùy chỉnh định dạng câu trả lời, văn phong và phong cách phản hồi của Claude Code theo ngữ cảnh công việc.

## 📦 Thành phần bao gồm

- **Skill (`response-formatting`)**: Quy chuẩn định dạng 5 phong cách trả lời chính (Concise, Executive Summary, Senior Architect, Socratic Tutor, Code-First).
- **Command (`/format-response`)**: Lệnh tùy chỉnh hoặc áp dụng nhanh phong cách phản hồi mong muốn.

## 🚀 Cách cài đặt

```bash
/plugin install answer-formatter@demo-claude-marketplace
```

## 💡 Cách sử dụng

```bash
/format-response concise
/format-response architect
```
